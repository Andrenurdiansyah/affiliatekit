# AffiliateKit AI

AffiliateKit AI adalah platform *all-in-one* yang dirancang khusus untuk para kreator konten dan pejuang *affiliate marketing* (TikTok/Shopee). Kami membantu mempercepat alur kerja pembuatan konten melalui otomatisasi berbasis AI.

## Fitur Utama

- **AI Caption Generator:** Membuat *caption* jualan berbasis formula AIDA yang terbukti meningkatkan konversi.
- **Viral Hook Generator:** Membuat *opening* video yang memancing penonton untuk tetap menonton.
- **Fake Comment Generator:** Alat pembuat *fake comment* (PNG transparan) untuk kebutuhan *social proof* di konten video.
- **Fake Chat Generator:** Generator percakapan chat tiruan untuk kebutuhan konten testimoni yang *realistis*.
- **SEO Ready:** Dioptimasi untuk mesin pencari dengan *Sitemap* dan *Robots.txt* yang terkonfigurasi.

## Stack Teknologi

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Language:** TypeScript
